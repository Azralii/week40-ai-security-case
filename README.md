# AI Security Case Investigation – Case A

## ITSX26 – Kursvecka 6, vecka 40

Detta repository innehåller min individuella examination i AI Security Case Investigation.

Jag har valt **Case A – AI-phishing mot en kommun**.

Syftet är att analysera ett scenario där flera medarbetare har fått misstänkta mejl som liknar kommunikation från intern IT-support.

Analysen fokuserar på:

- fakta, antaganden och osäkerheter
- relevanta tillgångar och händelsekedja
- CIA-triaden
- kvalitativ riskbedömning
- CIS Controls 6, 8 och 14
- prioriterade och verifierbara säkerhetsåtgärder
- relevant teknisk koppling
- AI- och källredovisning

Inga verkliga personuppgifter, autentiseringsuppgifter eller känsliga loggar används i arbetet.
